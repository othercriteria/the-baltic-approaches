# The Mission (1986)

*Working title.* A didactic novel of military doctrine: Goldratt's *The Goal*
transposed to AirLand Battle, set in a Red Storm Rising-like NATO/Warsaw Pact
war of 1986. Original characters and events; the setting is the shared
WWIII-'80s genre (Hackett, *Team Yankee*), not any particular book's furniture.

Target: 50–60k words. Successor project to
[white-buffalo](https://github.com/othercriteria/white-buffalo), iterating on
its instrumented long-form writing method at roughly double the scale.

Status: **pre-Phase-1 stub.** See `planning/premise.md` for the design sketch
and `planning/provenance.md` for where this idea came from.
